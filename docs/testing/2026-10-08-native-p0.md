Actual MSVC Tauri debug binary and WebView2, with Vite on localhost:1420. Isolated debug configuration `.tools/smoke-config`; only disposable synthetic sources in `.tools/smoke-repo`. This is native evidence, separate from the browser fixture suite. macOS has not been executed.

- Ten eligible files: README.md, eight src/fileN.ts, and src/tests/sample.ts. Root .gitignore ignores itself and dist/; dist/deep/generated.ts contains a sentinel.
- Native Save As chose a new **inside-workspace** `context-current.md`. Reported 10 files, 673 actual UTF-8 bytes; filesystem length was 673, with ten sections, language tags and no ignored sentinel.

## Ignore inspection and recovery

- Launched the actual binary with an isolated corrupt-settings profile containing 27 bytes. The original was preserved byte-for-byte in `settings-recovery/`; a visible notice explained the backup and defaults. Open Folder then saved valid settings and resumed operation.
- This deliberately separate, recovered profile has no generated-output registry. Consequently the earlier `context-current.md` is ordinary source in this profile. Recovery does not reconstruct lost settings; the normal-profile registry and restart behavior above remain separate evidence.
- Excluded README.md, disabled Respect .gitignore and applied: 12 selected, 17 discovered. Reenabled and applied: 10 selected, 15 discovered. README's explicit exclusion survived both policy changes.
- Browsed ignored dist and dist/deep lazily: generated.ts appeared, remained filtered, and the selected count stayed 10. Force include through its menu changed the count to 11 and displayed Override. Native Copy produced 1,381 UTF-8 bytes containing both its relative-path section and `must not appear` synthetic content.
- Reset override for that file restored 10 selected; the subsequent 1,318-byte clipboard output contained neither the ignored section nor its content. README stayed explicitly excluded. No source file was modified.
- This journey found the first menu action covered by virtual rows. A body portal fixed pointer targeting; the compact-window browser regression failed before the fix and passed afterward. Keyboard focus followup is tracked in the review log.
