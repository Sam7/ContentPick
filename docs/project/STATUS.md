## M4.5.1 bounded per-file token cache

## M4.5 integration and local M4 architecture/performance review

Token estimates now run away from the UI on a serial blocking worker, with their own cancellation and request identity. The selected manifest is tied to workspace generation, physical root and watcher epoch/revision; stale or late results are rejected.
